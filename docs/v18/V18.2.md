# V18.2 patch and feature test list

## What changed

1. **Jobs tab** (quick panel): the conversation (prompts, answers, steps; Full view and Clear conversation) is at the top of Jobs, the job list below. Actions holds only the action tiles and New action.
2. **Composer toolbar** (full screen): Attach, Save to, Allow folder, model dropdown, Auto-approve, the project / CLI / model / session line, then effort, Stop and Send. The header keeps only the title, Pin and Retry.
3. **Theme toggle**: the chat page (WebView) is updated by one small script that sets its colours, sent right after the WPF resources are swapped, plus the page's background colour. No full re-render.
4. **Profile menu**: placed in the body row under the top bar, scrolls if the window is short, closes on an outside click.
5. **Notifications panel**: permission requests, job completed / failed, files created (up to three listed, more become one line). Nothing is listed for jobs already finished before the app started. Opening the panel shows what is new; closing it marks everything read.

Not run here (needs the real window on Windows): the layout, the theme switch timing, the menu position.
